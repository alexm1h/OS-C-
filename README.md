## Список работ

### 1. Работа с файловой системой Windows (`file_system_win32.cpp`)
**Лабораторная работа №1.** Консольное приложение для управления файловой системой через Win32 API.
* Просмотр логических дисков (`GetLogicalDrives`).
* Получение информации о диске (метка, файловая система, свободное место).
* Создание/удаление директорий, копирование и перемещение файлов.
* Получение и изменение атрибутов и времени файла.

### 2. Асинхронный ввод-вывод в Linux (`async_copy_linux.cpp`)
**Лабораторная работа №2.** Копирование файлов с использованием POSIX AIO.
* Использование структур `aiocb` и функций `aio_read` / `aio_write`.
* Обработка завершения операций через колбэки (`SIGEV_THREAD`).
* Асинхронная обработка блоков файла (размер блока 4096 байт, до 16 одновременных операций).
* Замер времени и вывод скорости копирования (MB/s).

### 3. Разделяемая память: Memory Explorer (`MemoryExplorer.cpp`)
**Лабораторная работа №3.** Работа с отображением файлов в память (`mmap`).
* Создание и открытие разделяемой памяти.
* Блокировка страниц в ОЗУ (`VirtualLock`).
* Взаимодействие клиента и сервера через разделяемый файл `shared.dat`.

### 4. Клиент-сервер через разделяемую память (`client_server_mmap/`)
**Лабораторная работа №4.** Взаимодействие двух процессов через `mmap`.
* **Сервер** (`server.c`): создает файл, отображает его в память и записывает данные.
* **Клиент** (`client.c`): открывает файл и читает данные из разделяемой памяти.

### 5. Многопоточное вычисление числа Пи (Win32) (`pi_threads_win32.cpp`)
**Лабораторная работа №5.** Вычисление числа Пи методом прямоугольников с потоками Windows.
* `CreateThread`, `ResumeThread`, `SuspendThread`.
* Синхронизация через `CRITICAL_SECTION`.
* Динамическое распределение блоков между потоками.
* Замер времени через `QueryPerformanceCounter`.

### 6. Параллельное вычисление числа Пи (OpenMP) (`pi_openmp.cpp`)
**Лабораторная работа №6.** Вычисление числа Пи с использованием OpenMP.
* `#pragma omp parallel for schedule(dynamic)`.
* Редукция `reduction(+:totalSum)`.
* Сравнение производительности при 1, 2, 4, 8, 12, 16 потоках.

### 7. Задача «Читатели и Писатели» (Win32) (`readers_writers_win32/`)
**Лабораторная работа №7.** Синхронизация процессов (не потоков!) через именованные семафоры.
* **Manager** (`manager.cpp`): создает разделяемую память (`CreateFileMapping`) и семафоры, запускает дочерние процессы.
* **Reader** (`reader.cpp`) и **Writer** (`writer.cpp`): читают и пишут данные в разделяемые страницы.
* Использование `WaitForMultipleObjects`, `VirtualLock`, логирование в файлы.

### 8. Именованные каналы (Named Pipes) (`named_pipes_win32/`)
**Лабораторная работа №8.** Клиент-серверное взаимодействие через именованные каналы с асинхронным I/O.
* **Сервер** (`server.cpp`): создает канал (`CreateNamedPipe`), ожидает клиента, асинхронно пишет данные (`WriteFile` + `OVERLAPPED`).
* **Клиент** (`client.cpp`): подключается к каналу, использует асинхронное чтение через `ReadFileEx` с функцией обратного вызова.
